LIVE Framework

Learning interpretable visual rules from PuzzleScript state transitions.

Goal

The agent observes before-state, action, after-state triples and induces executable logical rules that can be verified against the recorded timeline and used for planning.

Observe

Collect ARC-compatible FrameData episodes from the local runtime.

Induce

Ask an LLM to propose structured rules from the accumulated transitions.

Verify

Check candidate rules against the timeline before relying on them.

Plan

Use verified rules in the runtime action loop.

Command

python -m studies.LIVE_framework.run --help
