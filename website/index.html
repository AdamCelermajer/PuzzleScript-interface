What this site communicates

  • The system shape: Python agent, ARC-compatible service, Node PuzzleScript runtime.
  • The finished static experiments and where their evidence lives inside the website.
  • The model-comparison evidence around reasoning traces, latency, and failure modes.
  • The next step: a local Python backend that can launch runs and stream logs later.

Runtime boundary

V1 is intentionally static. The browser reads local website assets only. A future live runner should be a separate local backend that starts explicit Python commands, captures logs, and writes run artifacts for the site to inspect.
