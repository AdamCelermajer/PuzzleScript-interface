The three projects are not the same kind of contribution

Put the collision in the correct place

VISTA is the real architecture challenge. AVO is a design lesson and baseline. PuzzleScript-World remains the instrument that can test both.

QuestionAVOVISTAPuzzleScript-World
Object of studySearch operatorAgent harnessEvaluation protocol
Knowledge substrateCode lineage, docs, profiler feedback, persistent agent memoryFree-form notes plus lossless visual historyModel-agnostic; makes the substrate an experimental variable
Primary evidenceAttention throughput on B200Public ARC-AGI-3 completion and action efficiencySolving, goal, transition, transfer, and resource diagnostics

Defensible thesis spine High task score does not explain how a system acquired the skill. PuzzleScript-World measures which representations and harness components help, what the agent actually predicts, where it fails, and what transfers.
