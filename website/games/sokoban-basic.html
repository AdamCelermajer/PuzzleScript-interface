Sokoban Basic

ps_sokoban_basic-v1 is the shared baseline for the local ARC service, LIVE rule-learning runs, and the thinking comparison.

Why it matters

Sokoban gives the agent a small deterministic world where movement, collision, pushing, targets, and win conditions can be observed through state transitions.

Run manually

npm run local
uv run python -m client.run_arc_agent --backend-url http://localhost:8000 --game-id ps_sokoban_basic-v1 --max_steps 50
