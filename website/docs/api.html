ARC-compatible API

The Python service exposes an ARC-style surface and forwards runtime actions to the Node PuzzleScript server.

Internal runtime

POST /init
POST /action
GET  /observe?sessionId=...

ARC adapter

GET  /api/games
GET  /api/games/{game_id}
POST /api/scorecard/open
GET  /api/scorecard/{card_id}
POST /api/scorecard/close
POST /api/cmd/RESET
POST /api/cmd/ACTION1..5
POST /api/cmd/ACTION7

Action mapping

ACTION1 up, ACTION2 down, ACTION3 left, ACTION4 right, ACTION5 space/action, ACTION7 undo.
