# How to learn an unknown game

- Early on, try each action and write down exactly what changed. Use undo to take back an experiment.
- Keep notes/rules.md with two lists: confirmed rules (a move showed them) and guesses (not yet tested). Move a guess to confirmed only after a move shows it.
- Before each move, write what you expect to change. When the result differs, fix the rule before going on.
- A move that changed nothing still costs an action. Find out why before trying it again.
- When a level is completed, write down what completed it.
