# World Model — Final Research Notes

## Objective and Best Outcome
A Sokoban-style puzzle played entirely through a CLI (`python game.py`). Four levels; each
has a grid with one character, one box, and one target tile. The run shares a single budget
of **1000 actions**: every `do ACTION` and every `reset` costs one action; `look` is free.
A level is won by pushing the box onto the target tile; the next level then starts
automatically.

**Best evaluated outcome: 3 of 4 levels completed** (level 1 at action 78, level 2 at 174,
level 3 at 404). Level 4 was *provably not completable within the remaining budget* (see
Critical discovery), so the run ended at 1000/1000 with the box 3 tiles from the target.

## Objects and State
- Level 4 grid: 9 rows x 11 columns (earlier levels were smaller/different; never fully mapped).
- Tiles, identified by stable numbers ("same picture = same number"): white floor (1), dark
  floor (2) — both walkable; dark-blue target (9); checker decoration (4).
- Box and character render as overlays: box on white (3) / dark (8) / checker (10);
  character on white (7) / dark (5) / checker (6).
- Level 4 start (observed after `reset`): character (4,0), box (4,1), target (0,3)
  (row, column from top-left).
- **Hidden walls** — the key object. Between some adjacent cells there is an invisible wall
  that blocks both character moves and box pushes. Walls are per edge (not per tile) and are
  only discoverable when a move is blocked. Level 4 has ~50 such edges; they split the map
  into a "blob" (central-right room), a "pocket" (below col 2), a "corridor" (central strip),
  and the row-0/row-1 and right-room areas.

## Controls
- `ACTION1/2/3/4` = up/down/left/right. If the destination cell holds the box and the cell
  beyond is free, the box is pushed one cell; otherwise the character moves one cell.
- A blocked move (hidden wall, board edge, or box pressed against a wall) prints
  "nothing changed" but **still consumes an action**.
- `ACTION7` = undo the last move; observed no-op if the last move was blocked.
- `reset` restarts the current level (costs 1 action). `look` re-displays the grid (free).

## Movement and Interactions (step by step)
1. Character attempts a step in a direction.
2. If the edge to the destination is a hidden wall, or the destination is off-board: nothing
   changes; the action is spent.
3. If the destination is empty: character moves there.
4. If the destination holds the box: the box moves one cell in the same direction **only if**
   the box's forward edge is not walled and the cell beyond is on-board; then the character
   takes the box's old cell. Otherwise nothing changes (action spent).
5. Boxes are push-only, never pulled; a box with perpendicular walls on two sides is lost.

## Goal and Level Transitions
Box on target = level won; the next level loads automatically with its own layout. What
happens after level 4 (final win state) was never observed.

## Undo and History
`ACTION7` restores the immediately preceding character/box positions. Only the last move is
undone; blocked moves are no-ops. Chain depth was never fully characterized.

## Critical Discovery — Why Level 4 Was Unfinishable
The level has essentially one viable winning line, and it is closed by confirmed walls:

1. The box can enter the target (0,3) from (0,2), (0,4), or (1,3); the (1,3)→(0,3) edge is
   a confirmed wall (tested in-game), leaving (0,2) or (0,4).
2. The column-2 line — box (4,2) → (3,2) → (2,2) → (1,2) → (0,2) → (0,3) — has **all box
   edges confirmed open**, but every push requires the character directly below the box.
   The character's only entrance to the pocket cells below column 2 is *through (4,2)
   itself*, usable only while the box is not on (4,2). Every other pocket-perimeter edge is
   a confirmed wall. So once the box parks on (4,2), the character can never get below it
   again.
3. Getting the box from its start to (4,2) therefore requires the character on the corridor
   side (e.g., at (4,4) to push the box left out of (4,3)). The corridor region connects to
   the character's blob region by exactly four bridge edges — **all four are confirmed real
   walls** (three tested in the final session; the fourth, even if open, would need 35+
   moves vs. 23 left).
4. The box's only live routes from (4,3) are a 4-cell ping-pong ring
   (4,3)-(5,3)-(5,4)-(4,4) and dead-end branches to (2,4) and (3,6).
