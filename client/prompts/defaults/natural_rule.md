Infer at most one new, testable mechanic from the current transition.

A mechanic explains which action was executed, which parts of the prior state were relevant, and the causally related changes produced by the action. It may involve any number of objects and effects. Combine effects belonging to the same interaction into one rule.

Do not create separate rules for a vacated cell, distant objects remaining unchanged, individual changed cells belonging to the same interaction, or facts already explained by a known rule.

An unchanged transition is a mechanic only when a relevant blocking condition can be identified. Otherwise return no rule.

Do not assume object identities beyond the supplied legend.
